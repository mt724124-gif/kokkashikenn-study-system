# 薬剤師国家試験学習システム｜個別最適化 v2

ChatGPTで **「勉強開始」「学習再開」** と入力して学習する。毎問、実ログと今回の回答・質問から理解状況を更新し、資料を読んで次の1問を決める。登録問題の有無・登録順・ランダム抽出を出題理由にしない。

## 唯一の入口と参照分岐
開始時はmainの最新Commitを取得し、そのSHAに固定してこのREADMEを読む。必要な行のマニュアルだけ読む。

| 入力・状態 | 読む順序 | 実行・停止条件 |
|---|---|---|
| 勉強開始・学習再開 | [学習開始](運用マニュアル/学習開始.md) → [学習者モデル](運用マニュアル/学習者モデル.md) → [復習管理](運用マニュアル/復習管理.md) | 実ログから状態を再構成。ユーザー指定・中断・期限・未学習から選ぶ |
| 区画決定・明示的な次へ | [個別作問](運用マニュアル/個別作問.md) → [資料参照](運用マニュアル/資料参照.md) → [問題演習](運用マニュアル/問題演習.md) | 最新の理解状況を踏まえて1問作成または選択 |
| 回答受領 | [問題演習](運用マニュアル/問題演習.md) → [追加質問](運用マニュアル/追加質問.md) | 採点・全選択肢解説・主観評価。自動で次問へ進まない |
| 追加質問 | [追加質問](運用マニュアル/追加質問.md) → 必要箇所だけ[資料参照](運用マニュアル/資料参照.md) | 同一問題に留まり、解説前後の理解を分けて保持 |
| この区画を完了・今日は終了 | [学習完了](運用マニュアル/学習完了.md) → [学習記録](運用マニュアル/学習記録.md) → [復習管理](運用マニュアル/復習管理.md) | 実回答だけ追記保存・再取得検証。終了と習得認定は別 |
| 中断 | [追加質問](運用マニュアル/追加質問.md) → [学習記録](運用マニュアル/学習記録.md) | checkpointを保存。未回答は未評価 |
| 問題不備 | [問題演習](運用マニュアル/問題演習.md) → [学習記録](運用マニュアル/学習記録.md) | 問題IDと版を無効化。既存ログを修正しない |

## 正本と補助データ
- [学習マスター](学習マスター/master.json)：1,344稼働区画、[ID移行台帳](学習マスター/ID移行台帳.json)。削除・上書きしない。旧IDの成績は子区画へ複製しない。
- `演習ログ/記録/*.md`：学習履歴の正本。既存外枠を維持し、v2イベントも同じフォルダへ追記。実演とテストを混ぜない。
- [問題運用索引](問題データ/運用索引.json)：現役の補助候補と履歴アーカイブの役割を分離。[旧45問](問題データ/questions.json)は本文・版・正答をそのまま保全。text問題は今後のUIで直接出さない。
- [復習仕様](運用マニュアル/復習管理.md)：知識項目ごとにログから算出。既存の復習JSON・ダッシュボードは旧ビューであり、取得しただけで最新とは扱わない。
- [v2検証・制限](運用マニュアル/v2_改修検証報告.md)、[現状調査・削除候補](運用マニュアル/v2_現状調査.md)。過去Phase報告は当時の記録で、現行仕様ではない。

## 初回設定と利用環境
[ChatGPT起動指示](運用マニュアル/ChatGPT起動指示.md)をプロジェクトに設定し、GitHub接続と必要な青本・青問を用意する。既存の起動指示がREADME参照を指定していれば、そのまま入口として使える。このMarkdownを置いただけでツール・UI・資料アクセスが付与されるわけではない。

毎回、利用環境でGitHub読取・資料本文・回答UI・書込の可否を区別して確認する。通常チャット・Work・定期タスクの能力を相互に推定しない。書込不可なら未保存ログを渡す。PDFがなければ該当資料の添付・確認できる公式資料・別区画の選択肢＋自由入力を示す。

本番保存は完了・終了・中断などの明示後。未同期のPC変更は確認できないため既存ファイルを更新せず、一意の新規ログのみ追記する。PDFをGitHubへ保存しない。他リポジトリを操作しない。

旧app・起動スクリプトは削除承認待ちで保全中。ChatGPT v2から呼び出さず、旧復習ビューの生成にも使わない。日量や5問を強制せず、理解と時間に応じて終了できる。

## 簡易勉強ノートと進行UI
[簡易勉強ノート](運用マニュアル/簡易勉強ノート.md)を復習作問の補助に利用する。解説後は「追加質問／次問／今日は終了」を主要操作とし、追加質問を選んだ場合だけ個別の質問候補3〜5件（複数選択可）と任意の自由回答欄を表示する。既存の復習必要性1〜5・問題完了・区画完了・中断も維持する。5問は目安で上限ではない。終了時は復習ログとノート候補を一括確認し、別途明示的な保存承認後にのみ保存する。
