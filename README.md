# 薬剤師国家試験 学習管理システム

青本（薬剤師国家試験対策参考書）を軸に、学習範囲・理解度・弱点・復習履歴をObsidianのMarkdownで管理するためのリポジトリです。

## 基本方針
- **正本はObsidian**。GitHubは同期・変更履歴の管理に使用します。
- ChatGPTは問題作成、採点、理解度の分析、学習計画、進捗の可視化を支援します。
- 学習済みと習得済みを区別し、正答率だけで理解度を確定しません。
- 青本・青問のPDF本体や著作物の大量転載は、このリポジトリに保存しません。
- 既存の別リポジトリ `drug-study-obsidian` は変更しません。

## ディレクトリ
| ディレクトリ | 用途 |
| --- | --- |
| `学習マスター/` | 青本の章・節・学習区画と進捗を管理 |
| `演習ログ/` | 日々の問題・回答・採点・理解度評価の記録 |
| `弱点ノート/` | 理解が不十分な知識と再復習の記録 |
| `学習ダッシュボード/` | 進捗可視化の定義・生成物 |
| `運用マニュアル/` | 出題・採点・記録・同期の運用ルール |

## 初期の学習設定（暫定）
- 新規学習：4区画 × 5問＝20問
- 復習：2区画 × 5問＝10問
- 合計：1日30問を基本とし、希望に応じて追加可能
- 4択1正解、5択2正解（完全正答）などの形式を将来導入
- 理解度は正誤・自信・自由記述・時間を空けた再確認を考慮

## 現在の状態
**初期フォルダ構成のみ作成済み。** 青本の全巻目次解析、学習区画の確定、学習マスターの作成、Obsidian同期、ダッシュボード実装は未実施です。未確認のページ番号や学習履歴を推測で登録しません。

## 安全な更新
GitHubへの更新前に最新版と競合を確認し、PC側のObsidianとの同期状態を確認します。未同期のローカル変更がある場合は上書きせず作業を停止します。
