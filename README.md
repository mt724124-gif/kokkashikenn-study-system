# 薬剤師国家試験学習システム｜ChatGPTから学習

日々の学習は、このプロジェクトのチャットで **「勉強開始」** と入力して進めます。ローカルアプリの起動は不要です。

## 初回だけ行う設定
プロジェクトの指示欄に、[ChatGPT起動指示](運用マニュアル/ChatGPT起動指示.md)のコードブロック内を貼り付けてください。GitHub接続でこのリポジトリを選択し、使う青本・青問を同じプロジェクトに添付します。設定自体はユーザーの画面で行います。このREADMEを置いただけでは、新しいチャットへの自動適用は保証されません。

GitHubへの読み書きとPDF参照は環境ごとに開始時確認します。通常チャットで保存機能がなければ、追記用ログを受け取り、書込み可能なWorkへ同じログを渡す手動経路を使います。未保存の結果を保存済みと呼びません。

## 読む順序と分岐
| 入力・状態 | 次に読むファイル | 次の行動 |
|---|---|---|
| 勉強開始・再開 | [学習開始](運用マニュアル/学習開始.md) → [復習管理](運用マニュアル/復習管理.md) | 接続・資料・履歴を取得し区画決定 |
| 区画決定 | [問題演習](運用マニュアル/問題演習.md) | 根拠を照合して1問提示 |
| 解答受領 | [問題演習](運用マニュアル/問題演習.md) → [追加質問](運用マニュアル/追加質問.md) | 採点・解説・追加質問。明示的な次へを待つ |
| 次へ・この問題は完了 | [追加質問](運用マニュアル/追加質問.md) | 次の1問。区画末なら学習完了へ |
| 区画終了・今日は終了 | [学習完了](運用マニュアル/学習完了.md) → [学習記録](運用マニュアル/学習記録.md) | 実回答・評価・復習日を保存し再取得 |
| 中断・再開 | [追加質問](運用マニュアル/追加質問.md) → [学習記録](運用マニュアル/学習記録.md) | checkpointから同じ問題へ戻る |
| 問題の誤り・訂正 | [問題演習](運用マニュアル/問題演習.md) → [学習記録](運用マニュアル/学習記録.md) | 問題版を無効化し追記訂正 |

## 記録の保護
Obsidianを正本とする既存方針を維持します。PC内はこのWorkから確認できません。既存ファイルへ追記・ビュー更新する前に未同期変更の有無を確認します。未確認時は一意な新規ログだけを保存し、既存ログ・マスター・復習ビューを上書きしません。ユーザーが既に回答した安全条件は繰り返し質問せず、状況変化があるときだけ確認します。青本・青問PDFはGitHubへ保存しません。他リポジトリを操作しません。

日量30問は初期の暫定案です。今回は1区画5問を基本とし、時間・体調・希望に応じて途中終了できます。
