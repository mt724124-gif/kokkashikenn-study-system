# 復習管理｜知識項目ごとの派生状態

正本は演習ログ。旧 `復習管理/復習予定.json`・Markdown・`学習ダッシュボード/進捗.md`は旧版の派生ビューで、最新履歴の代用にしない。v2は読み込んだログから知識ID別に都度再構成する。書込み権限がなくても再構成・表示は可能。

## 初期ルール（暫定、医学的・心理測定的な最適性を保証しない）

| 知識の状態 | 基本間隔 | 次の内容 |
|---|---:|---|
| 誤答・正答でも理由不明・再発 | 1日 | 前提を含む弱点診断 |
| 解説後に理解した申告のみ | 3日 | 異なる状況の定着確認 |
| 正答、未確認点なし | 7日 | 別問題で理由も確認 |
| 7日以上空いた別問題で正答＋理由確認 | 21日 | 応用と長期確認 |
| 参照資料・採点不明 | 1日後の確認候補 | 不明の解消。誤答扱いしない |

主観の復習必要性1/2/3はそれぞれ1/2/3日を希望上限として、基本間隔との短い方を採用。4/5は基本間隔を延ばさず、客観的な弱点を消さない。これは旧理解度ランクとは別のv2運用ルール。必要性未取得はnullのまま。最終学習日時を日本時間へ変換し暦日で加算。同日だけの再確認は長期定着にならない。

再発・誤答の事実は回数と根拠を残し、1日間隔と前提知識を優先。過去の復習回数・同一問題反復も表示するが、回数だけで定着へ上げない。未回答には学習日を付けない。

優先：ユーザー指定→中断の現在phase→期限到来かつ理解不足→定着確認待ち→その他の期限→未学習。正答＋理由不明は弱点群。期限前で仕組みまで理解した概念は必要に応じて応用へ。固定問題がある区画を優先しない。

派生表示は `source_commit / last_event_id / generated_at / rule_version=2 / 取得範囲とwarnings` を付ける。モデルやビューを保存してもキャッシュでありログから再構成可能にする。旧IDの履歴は関連表示、子区画へ得点コピー禁止。旧appでビューを書き戻さない。

## 簡易ノート連携
テーマ別簡易ノートを復習論点とひっかけの補助として参照する。正誤・復習期日・定着判定の正本は実演習ログ。ノートの存在を習得の証拠にしない。根拠が古い・未確認の内容は再確認する。
