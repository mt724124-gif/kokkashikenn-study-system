# 学習開始・再開

1. 対象は `mt724124-gif/kokkashikenn-study-system` のみ。main最新Commit SHA・treeを取得し、そのSHAのREADMEから分岐する。検索結果の抜粋・存在確認を本文取得と扱わない。
2. 学習マスターの該当区画、ID移行台帳、全ログ一覧と必要本文を読む。全件取得が難しい場合は期間・未取得範囲を明記し、未取得を未学習と断定しない。大きいJSONのcontentが空なら同じblob SHAで再取得する。読み込み失敗を空データへ置換しない。
3. `学習者モデル.md`に従って正誤・自由回答・追加質問・主観評価・解説後の申告を再構成。直近の未保存会話も別枠で加える。旧question_revision/question_report、原IDと暫定代替、旧区画との関連を解決する。
4. ユーザー指定を最優先。指定がなければ中断セッション、期限到来の弱点知識、未学習を候補にする。科目・区画の質問が必要なら実在IDの選択肢＋自由入力。「登録5問がある」は選定理由にしない。
5. PDFがこの会話で開けるか、該当本文が読めるかを別々に確認。`資料参照.md`に従う。青本ページを青問に流用しない。青問物理が未提供なら未提供と示す。
6. セッションUUID・開始時Commit・区画・最新checkpointのphaseを保持。完了セッションの古いcheckpointへ戻らない。中断中なら回答済み問題を再出題せず同じphaseへ戻る。
7. `個別作問.md` → `問題演習.md`で次の1問を作る。新規セッションは問題リストを最初に5問固定せず、回答ごとに再判断する。

読取・書込・PDF・UIは今の環境で確認した結果のみを表示。読取不可なら取得資料の提供を求め、最新履歴を参照済みとはしない。取得機能と書込成功実績は別。
