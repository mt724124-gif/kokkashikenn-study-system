# 個別作問｜毎問判断

## 毎回作る出題計画
次問への明示的な指示を受けたら、直近の回答・追加質問を含むモデルを更新する。区画・重要知識・理解済み/未確認・誤答・前提不足・解説後申告・過去の同一/類似出題・復習期日・参照資料を確認し、次を計画欄へ保持する。

`unit_id / concept_ids / mode / estimated_difficulty / selection_reason / evidence_event_ids / avoid_question_ids / source_requirements / reuse_or_generate`

画面には出題理由を短く示す。推定を事実や客観的難易度として表示しない。登録問題を使うのは、現在の目的・難度・重複回避・根拠確認を満たす場合だけ。旧45問を順番に消化しない。

| 状態 | モードと次の確認 |
|---|---|
| 未学習・前提不明 | 基礎確認。用語と構成要素を診断 |
| 正答でも説明できない | 弱点補強。構造・理由を問う新しい選択問題 |
| 誤答・分類混同 | 弱点補強。原因候補を断定せず前提の分類を診断 |
| 解説後に理解を申告 | 定着確認。直後は理解確認、後日を定着確認として区別 |
| 理由まで理解・期限前 | 応用。別の現象との関係を確認 |
| 基礎・応用を確認済み | 国試実践。実過去問または国試相当の独自作問 |
| 同じ誤解が再発 | 前提へ戻り、復習優先度を上げる |

難易度は暫定の1=用語、2=基本概念、3=仕組み、4=統合応用、5=国試実践/臨床判断。国試出題頻度・重要度とは別。低難度で前提が不足すればさらに戻る。

## BIO-0001の判断例（実ログ参照）
- リン脂質：正答でも「何なのかわかんない」→親水性頭部と疎水性鎖の構造を問う。旧第1問を繰り返さない。
- 膜タンパク質：誤答＋セルロース混同→タンパク質と糖質の成分分類へ戻る。
- 糖鎖：初期不明、追加説明後「本人理解」→両方保持し、小胞内腔側と細胞外側の関係を別の状況で確認。定着済みにしない。
- 二重層：配向を理解→膜透過性などへ発展。弱点の補強を優先し、この応用を先に出す義務はない。
- 流動モザイク：代替選択式の暫定正答、概念は初学→新IDの選択式で機構確認。元textは未回答。

同じ解法・正答文を覚えているだけの問題を避ける。重複が教育上必要なら目的・前回との差を記録。全区画5問や得点だけの習得認定は不要。
