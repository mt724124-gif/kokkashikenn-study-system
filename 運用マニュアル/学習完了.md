# 学習完了

「この区画を完了」「今日は終了」等の明示を受けるまで区画完了としない。最終問の解説後にも「区画完了・保存／追加質問／中断」＋自由回答欄を出す。実際に返答が来る前に完了イベントを作らない。

1. 実際の回答、選択問題の正誤、自由記述の自己評価、追加質問、未解決事項を一覧にする。無効問題は除外、未回答は未評価。解答時間は測れていなければ不明。
2. 全採用問題に回答した場合のみ、既存startと対応するsubmit（全answers）・assessment（自由記述scores）を追記する。開始・問題改訂イベントも同時に未保存なら一緒に保存。解説を読んだ後の言い直しは初回回答の置換とせずcheckpointへ追記。
3. 途中終了はcheckpointとsession_pauseのみ保存し、session_completeやsubmitを作らない。
4. 全回答済みで完了を明示した場合、session_completeにsession_id,unit_id,weak_topics,unresolved,self_understanding,completion_text,next_reviewを記録。主観的理解度は客観採点と別に持つ。
5. 復習日と評価は`復習管理.md`に従う。試用問題の範囲の暫定評価であることを明記する。
6. `学習記録.md`に従い保存・再取得検証。Commit SHA、保存パス、保存済み/未保存、次回復習日を短く報告して終了。新しい区画は勝手に開始しない。
